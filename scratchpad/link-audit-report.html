Why these 16 aren't called "broken"

A plain HTTP request to a link isn't a reliable test — some sites block requests that don't look like a real browser. That was confirmed directly during this run: a raw request to Facebook returned 400, but a real browser navigation to the identical URL returned 200. So every link here was checked via an actual page navigation, not a bare request.

Even after that fix, x.com and electoralcommission.org.uk still return 403 to a real (headless) Playwright browser. That's most likely bot detection on their end rather than the pages being gone — but it can't be told apart from a genuine block without evading that detection, which this audit deliberately doesn't attempt. So anything that 403'd only on an external, non-Democracy-Hub domain is reported here as ambiguous rather than broken. A 403 on the site itself would have been reported as a real, confirmed failure — none occurred.

11 links pointing straight at PDF files (evaluation reports, FAQs, toolkits) needed a separate check, since a browser can't "load" a file it's about to download — each was confirmed with a direct request instead, and all returned 200.
